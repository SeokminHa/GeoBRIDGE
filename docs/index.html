GeoBRIDGE pairspace experiments (indirect)

Companion site for the code repository: synthetic benchmarks with indirect velocity effects, and pancreas real-data analysis (Fig. 3 style).

Source code: GitHub repository · README.md

Quick start

  • Clone the repo and install dependencies: pip install -r requirements.txt
  • Benchmarks: python run_all.py --reps 3 --drift-reps 2 --n-cells 400 --indirect-strength 0.35
  • Pancreas: python -m real_1_Pancreas.pancreas_fig3 (from repo root)
